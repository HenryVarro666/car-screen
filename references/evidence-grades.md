# 选装证据等级

每个选装字段记两样：值和证据等级。

| 等级 | 是什么 | 能证明什么 |
|---|---|---|
| A | 同 VIN 的原厂窗贴、配置表或选装代码清单 | "有"和"没有"都能证明 |
| B | 卖家针对这一台车写的文字（单车页上列出的选装） | 只能支持"有" |
| C | 聚合网站的模板、概述、关键词命中、AI 问答 | 什么都不能证明，不记录为证据 |

## 规则

- **"没有"只能来自 A 级，而且清单要完整。** 完整的标志是：基础价加全部选装和运费，等于窗贴总价。对不上就说明清单不全，缺的那一项只能记"待核"。
- 不列价格的清单（如 CarMax 的 Vehicle Label）上没出现某个选装，记"待核"，不记"没有"。
- 第三方按 VIN 重建的窗贴算 A 级，备注"重建"。
- 只有 C 级线索时，值填 `unknown`，并在 `tried` 里记下查过哪个渠道。
- B 级升到 A 级时，在这台车的状态记录里追加一行带日期的说明。

脚本会强制其中两条：值不是 `unknown` 就必须有等级；`absent` 必须是 A 级。

## 常见误判

- 名字相近的不是同一个东西。"随速助力转向""驾驶模式含转向"不等于某个单独的转向选装包。
- 标配功能和选装包同名时，看选装代码或价格行。
- 车商页上的"功能亮点"常是整个车型的模板，同一车型的每台车都一样。翻两台车对比一下就能看出来。
- 照片能支持"有"（如座椅缝线、卡钳颜色），不能证明"没有"。照片也可能是库存图或 AI 生成的宣传图。

## 写进观察记录

```json
"options": {
  "sportPackage":      { "value": "present", "evidence": "A", "source": "官网 Window Sticker，选装合计对上总价" },
  "appearancePackage": { "value": "plus",    "evidence": "B", "source": "单车页 Optional equipment" },
  "adaptiveSteering":  { "value": "unknown" }
},
"tried": [
  { "field": "adaptiveSteering", "channel": "dealer", "result": "窗贴链接失效" }
]
```

只写这次查到的字段，没查的不用带。每个字段各自保留最新一次的结果。
